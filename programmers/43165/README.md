# 43165. 타겟 넘버

정수 배열 `numbers`의 순서를 유지하면서 각 숫자를 더하거나 빼서 `target`을 만드는 방법의 수를 구한다. 숫자는 2개 이상 20개 이하이며, 각 숫자는 1 이상 50 이하, 목표값은 1 이상 1,000 이하이다. [문제 원문](https://school.programmers.co.kr/learn/courses/30/lessons/43165)

예를 들어 `[1, 1, 1, 1, 1]`로 3을 만들려면 다섯 숫자 중 하나만 빼면 되므로 5가지 방법이 있다. `[4, 1, 2, 1]`로 4를 만드는 방법은 `+4+1-2+1`과 `+4-1+2-1`의 2가지다.

## 깊이 우선 탐색(DFS)

각 숫자에서 더하기와 빼기 두 가지 선택을 재귀 호출로 탐색한다. `cnt`는 지금까지 사용한 숫자의 개수이자 다음에 사용할 숫자의 인덱스이고, `value`는 현재까지 계산한 합이다.

`numbers[cnt]`를 더하는 경로와 빼는 경로로 나누어 모든 부호 조합을 확인한다. 숫자를 모두 사용했을 때만 목표값과 비교하므로, 각 조합을 정확히 한 번씩 세게 된다. 같은 값을 가진 숫자도 위치가 다르면 각각 별도의 선택으로 처리한다.

## 풀이

`solution()`에서 결과를 세는 전역 변수 `res`를 0으로 초기화한 뒤 `dfs(numbers, target, 0, 0)`을 호출한다.

`cnt == len(numbers)`이면 모든 숫자를 사용한 상태다. 이때 `value == target`이면 `res`를 1 늘리고, 목표값과의 일치 여부와 관계없이 현재 탐색을 끝낸다. 아직 숫자가 남았다면 현재 숫자를 더한 경우와 뺀 경우를 각각 재귀 호출한다.

모든 탐색이 끝나면 `res`를 반환한다. 초기 코드에는 `solution()` 내부의 초기화가 없어 같은 실행 환경에서 여러 번 호출하면 이전 결과가 누적되었다. 공식 예제를 순서대로 호출하면 5 다음에 2가 아닌 7이 반환된다. 이를 막기 위해 `solution()`에 `global res`와 `res = 0`을 추가했다.

숫자 개수를 n이라 하면 가능한 부호 조합이 2ⁿ개이므로 시간 복잡도는 O(2ⁿ)이다. 재귀 호출의 최대 깊이는 n에 비례하므로 추가 공간 복잡도는 O(n)이다.
