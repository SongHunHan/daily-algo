# 42748. K번째수

각 명령 `[i, j, k]`에 따라 배열의 i번째부터 j번째까지 잘라 오름차순으로 정렬하고, 그중 k번째 값을 구한다. 모든 명령의 결과를 순서대로 배열에 담아 반환한다. [문제 원문](https://school.programmers.co.kr/learn/courses/30/lessons/42748)

예를 들어 배열 `[1, 5, 2, 6, 3, 7, 4]`에 명령 `[2, 5, 3]`을 적용하면 `[5, 2, 6, 3]`을 잘라낸다. 정렬한 결과는 `[2, 3, 5, 6]`이므로 세 번째 값인 `5`를 구한다.

## 슬라이싱과 정렬

Python 리스트의 인덱스는 0부터 시작한다. `array[start:end]`는 시작 인덱스를 포함하고 끝 인덱스는 포함하지 않는다. 따라서 i번째부터 j번째까지의 구간은 `array[i - 1:j]`로 가져온다.

`sorted()`는 주어진 값들을 오름차순으로 정렬한 새 리스트를 반환한다. 정렬된 리스트의 k번째 값은 인덱스 `k - 1`로 찾는다.

## 풀이

각 명령에서 `i`, `j`, `k`를 꺼낸다. `array[i - 1:j]`로 구간을 자르고 `sorted()`로 정렬한 뒤, `new_array[k - 1]`을 결과 리스트에 추가한다. 모든 명령을 처리하면 결과 리스트를 반환한다.

배열 길이를 n, 명령 수를 m이라 하면 시간 복잡도는 O(mn log n)이다. 정렬할 구간에 최대 O(n), 결과 리스트에 O(m) 공간을 사용한다.
