# 42586. 기능개발

각 기능의 현재 진도와 하루 작업 속도가 주어진다. 진도가 100 이상이면 배포할 수 있으며, 배포 순서는 주어진 기능 순서를 따른다. 뒤의 기능이 먼저 완료돼도 앞의 기능이 배포될 때까지 기다려야 한다. 각 배포에서 함께 배포하는 기능의 개수를 반환한다. [문제 원문](https://school.programmers.co.kr/learn/courses/30/lessons/42586)

예를 들어 진도가 `[93, 30, 55]`, 속도가 `[1, 30, 5]`이면 7일째에 앞의 두 기능을, 9일째에 마지막 기능을 배포하므로 `[2, 1]`을 반환한다.

## 큐(Queue)

큐는 먼저 넣은 값부터 꺼내는 자료구조다(FIFO). Python의 `deque`에서 `popleft()`를 사용하면 맨 앞의 값을 꺼낼 수 있다. 기능을 배포 순서대로 보관하고, 완료된 기능을 앞에서부터 꺼내는 데 사용한다.

## 풀이

진도와 속도를 각각 `deque`로 바꾼다. 하루가 지날 때마다 남아 있는 모든 기능의 진도에 해당 속도를 더한다.

맨 앞부터 진도가 100 이상인 기능의 개수를 센다. 아직 완료되지 않은 기능을 만나면 뒤의 기능도 기다려야 하므로 확인을 멈춘다.

함께 배포할 기능의 개수만큼 두 큐에서 `popleft()`로 진도와 속도를 함께 제거한다. 배포한 기능이 있으면 그 개수를 결과에 추가하고, 모든 기능이 배포될 때까지 반복한다.
