# 12909. 올바른 괄호

`(`와 `)`로 이루어진 문자열에서 괄호가 올바르게 짝지어졌는지 판단한다. 여는 괄호마다 뒤에 닫는 괄호가 있어야 하며, 닫는 괄호가 먼저 나와서는 안 된다. 문자열의 길이는 1 이상 100,000 이하이다. [문제 원문](https://school.programmers.co.kr/learn/courses/30/lessons/12909)

예를 들어 `"()()"`와 `"(())()"`는 `True`, `")()("`와 `"(()("`는 `False`를 반환한다.

## 스택(Stack)

스택은 마지막에 넣은 값부터 꺼내는 자료구조다(LIFO). Python의 리스트를 스택으로 쓸 때는 `append(x)`로 끝에 넣고 `pop()`으로 마지막 값을 꺼낸다.

## 풀이

문자열을 앞에서부터 읽으며 `(`를 만나면 스택에 넣는다. `)`를 만났을 때 스택이 비어 있으면 짝을 맞출 여는 괄호가 없으므로 `False`를 반환한다. 스택에 여는 괄호가 있으면 `pop()`으로 하나를 꺼내 짝을 맞춘다.

모든 문자를 확인한 뒤에도 스택에 괄호가 남아 있으면 닫히지 않은 괄호가 있으므로 `False`를 반환한다. 스택이 비어 있으면 모든 괄호의 짝이 맞으므로 `True`를 반환한다.

문자열의 길이가 n일 때 시간 복잡도는 O(n), 추가 공간 복잡도는 O(n)이다.
