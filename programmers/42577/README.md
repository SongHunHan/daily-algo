# 42577. 전화번호 목록

전화번호 목록에서 어떤 번호가 다른 번호의 접두어이면 `False`, 그런 경우가 없으면 `True`를 반환한다. 접두어는 문자열의 맨 앞부분을 뜻한다. 예를 들어 `"119"`는 `"1195524421"`의 접두어다. 전화번호는 최대 1,000,000개이며, 각 번호의 길이는 최대 20이고 중복은 없다. [문제 원문](https://school.programmers.co.kr/learn/courses/30/lessons/42577)

## 정렬과 접두어 비교

`sort()`는 전화번호 문자열을 사전순으로 정렬한다. 같은 접두어로 시작하는 번호들이 모이고, 접두어가 되는 짧은 번호가 먼저 놓인다. 따라서 접두어 관계가 있다면 정렬된 목록에서 인접한 번호를 비교할 때 찾을 수 있다.

`문자열.startswith(접두어)`는 문자열이 해당 접두어로 시작하면 `True`를 반환한다.

## 풀이

전화번호 목록을 정렬한 뒤, 각 번호가 바로 다음 번호의 접두어인지 확인한다. 접두어 관계를 찾으면 `answer`를 `False`로 바꾸고 반복을 멈춘다. 끝까지 찾지 못하면 `True`를 반환한다.

초기 코드에서는 `phone_book.sort()`가 주석 처리돼 있었다. 공식 첫 예제 `["119", "97674223", "1195524421"]`에서는 접두어 관계인 두 번호가 떨어져 있어 `True`가 반환된다. 정렬을 실행하도록 수정하면 `"119"`와 `"1195524421"`이 이웃하므로 올바르게 `False`를 반환한다.

번호 개수를 n, 최대 번호 길이를 L이라 하면 시간 복잡도는 O(nL log n)이다. L은 최대 20이므로 번호 개수를 기준으로 O(n log n)으로 볼 수 있다.
