# 42840. 모의고사

세 사람이 각자 정해진 패턴을 반복해 답을 찍는다. 정답 배열 `answers`가 주어지면 가장 많이 맞힌 사람의 번호를 구한다. 최고 점수가 같으면 해당하는 사람을 모두 번호 오름차순으로 반환한다. [문제 원문](https://school.programmers.co.kr/learn/courses/30/lessons/42840)

예를 들어 정답이 `[1, 2, 3, 4, 5]`라면 1번이 모든 문제를 맞혀 `[1]`을 반환한다. 정답이 `[1, 3, 2, 4, 2]`라면 세 사람 모두 2문제씩 맞히므로 `[1, 2, 3]`을 반환한다.

## 완전탐색과 나머지 연산

각 사람의 반복 패턴을 `per_1`, `per_2`, `per_3`에 저장한다. 패턴 길이는 각각 5, 8, 10이다. 모든 문제에서 세 사람의 답을 정답과 비교해 맞힌 개수를 센다.

문제의 인덱스 `idx`를 패턴 길이로 나눈 나머지 `idx % len(per_1)`은 해당 문제에서 사용할 패턴의 위치다. 예를 들어 길이가 5인 패턴은 인덱스가 5일 때 다시 0번째 값을 사용한다. 이 방식으로 패턴을 늘리지 않고도 모든 문제의 답을 확인할 수 있다.

## 풀이

`enumerate(answers)`로 문제 인덱스와 정답을 함께 가져온다. 각 패턴에서 나머지 연산으로 답을 찾고, 정답과 같으면 `cnt_1`, `cnt_2`, `cnt_3`을 각각 1씩 늘린다.

모든 문제를 확인한 뒤 `max(cnt_1, cnt_2, cnt_3)`으로 최고 점수를 구한다. 세 사람의 점수를 번호순으로 순회하며 최고 점수와 같은 사람의 번호 `idx + 1`을 결과에 추가한다. 번호순으로 추가하므로 동점자가 있어도 별도의 정렬 없이 오름차순을 유지한다.

문제 수를 n이라 하면 각 문제에서 세 번 비교하므로 시간 복잡도는 O(n)이다. 패턴과 점수, 결과 배열의 크기는 문제 수와 관계없이 일정하므로 추가 공간 복잡도는 O(1)이다.
