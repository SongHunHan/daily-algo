# 42578. 의상

의상의 이름과 종류가 주어질 때, 서로 다른 옷차림의 개수를 구한다. 각 종류에서 최대 한 개의 의상을 선택할 수 있고, 전체에서 최소 한 개는 입어야 한다. [문제 원문](https://school.programmers.co.kr/learn/courses/30/lessons/42578)

예를 들어 모자 2개와 안경 1개가 있다면, 모자만 쓰는 2가지, 안경만 쓰는 1가지, 모자와 안경을 함께 쓰는 2가지로 총 5가지다.

## 해시와 경우의 수

Python의 `dict`를 사용해 의상 종류를 키로, 해당 종류의 의상 개수를 값으로 저장한다. `get(cloth_type, 0)`은 아직 없는 종류라면 기본값 `0`을 반환한다.

한 종류에 의상이 k개 있으면 하나를 고르는 k가지와 그 종류를 입지 않는 1가지를 합쳐 선택지는 k + 1개다. 종류별 선택은 서로 독립적이므로 각 종류의 선택지 수를 곱한다.

## 풀이

의상을 순회하며 `cloth_dict`에 종류별 개수를 센다. 곱셈의 시작값인 `res`를 1로 두고, 각 개수에 1을 더한 값을 차례로 곱한다.

곱한 결과에는 모든 종류를 입지 않는 경우가 한 번 포함된다. 최소 한 개는 입어야 하므로 마지막에 1을 빼서 반환한다. 모자 2개와 안경 1개라면 `(2 + 1) * (1 + 1) - 1 = 5`가 된다.

의상 수를 n, 종류 수를 t라 할 때 딕셔너리 연산의 평균 비용을 기준으로 시간 복잡도는 O(n), 추가 공간 복잡도는 O(t)이다.
