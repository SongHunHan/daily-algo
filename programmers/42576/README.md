# 42576. 완주하지 못한 선수

참가자 명단 `participant`와 완주자 명단 `completion`이 주어진다. 참가자 중 정확히 한 명이 완주하지 못했으며, 그 선수의 이름을 반환한다. 동명이인이 있을 수 있으므로 이름별 인원수까지 확인해야 한다. [문제 원문](https://school.programmers.co.kr/learn/courses/30/lessons/42576)

예를 들어 참가자가 `["mislav", "stanko", "mislav", "ana"]`, 완주자가 `["stanko", "ana", "mislav"]`이면 `"mislav"`를 반환한다. 같은 이름의 참가자 두 명 중 한 명만 완주했기 때문이다.

## 해시(Hash)

해시 테이블은 키에 연결된 값을 빠르게 저장하고 찾는 자료구조다. Python의 `dict`를 사용해 이름을 키로, 해당 이름의 인원수를 값으로 저장한다. `get(이름, 0)`은 이름이 아직 없으면 기본값 `0`을 반환한다.

## 풀이

참가자 명단을 순회하며 이름별 인원수를 1씩 더한다. 이어서 완주자 명단을 순회하며 같은 이름의 인원수를 1씩 뺀다.

모든 완주자를 확인하면 완주하지 못한 선수의 이름에만 인원수 1이 남는다. `items()`로 이름과 남은 인원수를 확인하며 값이 1인 이름을 반환한다.

참가자 수가 n일 때 딕셔너리 조회와 갱신의 평균 비용을 기준으로 시간 복잡도는 O(n), 추가 공간 복잡도는 O(n)이다.
